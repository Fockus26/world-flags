# D005 · Tokens · `--field-background` = gris suave (no blanco) para separar inputs/selects del blanco de tarjetas/modales · Implementado

**Decisión:** `--field-background` = `#f1eff8` (claro) / `#2b2740` (oscuro) — un gris muy suave, no el blanco/gris-del-modal
**Por qué:** Inputs y selects se fundían con el blanco de las tarjetas y modales ("se ve transparente"). También se subió `--field-border` a `#9c96c4` / `#6f6a94` para ≥3:1
